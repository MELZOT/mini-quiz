# Mini Quiz App

Μια απλή εφαρμογή quiz φτιαγμένη με **React**, **TypeScript** και **Vite** στο πλαίσιο εκπαιδευτικής εργασίας.

## Περιγραφή
Η εφαρμογή εμφανίζει ερωτήσεις πολλαπλής επιλογής.  
Ο χρήστης επιλέγει απάντηση, προχωρά στην επόμενη ερώτηση και στο τέλος βλέπει το τελικό σκορ με 
δυνατότητα επανεκκίνησης του quiz.

## Τεχνολογίες
- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)

## Λειτουργίες
- Εμφάνιση ερωτήσεων πολλαπλής επιλογής
- Επιλογή απάντησης
- Υπολογισμός σκορ
- Οθόνη τελικού αποτελέσματος
- Επανεκκίνηση quiz

## Δομή Components
- `App` – αρχικό component της εφαρμογής
- `Quiz` – διαχείριση λογικής και state
- `OptionList` – εμφάνιση επιλογών απάντησης
- `Button` – επαναχρησιμοποιήσιμο κουμπί
- `ResultScreen` – εμφάνιση τελικού σκορ
